# visual-shape-training
# 見る力を育てる図形トレーニング

**見て、考えて、図形を写そう。**

学校・福祉施設・家庭などでの学習や支援に活用できる、無料のWebアプリです。

## アプリについて

本アプリは、図形や点の配置を見て、形や位置関係を認識する練習を行うための学習支援ツールです。

教育活動、個別学習、福祉施設での支援、家庭での学習など、さまざまな場面での活用を想定しています。

## 利用方法

ブラウザからアクセスして利用できます。アプリのインストールは不要です。

- 学校での授業や個別学習
- 福祉施設での学習・支援活動
- 家庭での学習やトレーニング
- 学習・支援に必要な範囲での画面の印刷と配布

本アプリの利用料は無料です。
